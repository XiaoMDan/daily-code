# 算法练习区

这里专门留给你刷题和复盘。

## 当前结构

- `easy/`
  - 独立 Maven 模块
  - 代码写到 `src/main/java/`
- `medium/`
  - 独立 Maven 模块
  - 代码写到 `src/main/java/`
- `hard/`
  - 独立 Maven 模块
  - 代码写到 `src/main/java/`
- `templates/`
  - 常用代码模板

## IDEA 使用方式

1. 直接打开 `practice/algorithms`
2. 让 IDEA 导入 Maven 项目
3. `easy / medium / hard` 会被识别为 3 个子模块
4. 以后在 `easy/src/main/java` 里就可以直接新建 `.java` 文件

## 建议命名

- `TwoSum001.java`
- `ValidParentheses020.java`
- `ReverseLinkedList206.java`

## 每道题建议记录

1. 题目名
2. 核心思路
3. 时间复杂度
4. 容易错的点
5. 二刷总结

# StudyHelper

这是我当前的 Java 后端学习工作区，按“项目 / 笔记 / 计划 / 练习 / 工具”来组织。

## 推荐目录结构

- `projects/`
  - 放项目源码、项目副本、实验项目
- `notes/`
  - 放学习笔记、项目笔记、求职笔记
- `plans/`
  - 放学习计划、任务安排、表格
- `practice/`
  - 放算法题、SQL 练习、代码练习
- `scripts/`
  - 放自动化脚本
- `tools/`
  - 放 Maven、配置文件、环境说明

## 当前重要内容

- `yuapi-backend-master/`
  - API 开放平台后端源码
- `yuapi-frontend-master/`
  - API 开放平台前端源码
- `nacos-docker/`
  - Nacos 本地环境
- `daily-code/`
  - 你原来单独维护的日常代码仓库

## 建议使用方式

1. 项目源码先继续保留在原路径，避免影响已经跑通的环境
2. 以后新的学习笔记优先写到 `notes/`
3. 算法题统一写到 `practice/algorithms/`
4. SQL 练习统一写到 `practice/sql/`

## 后续可继续整理

- 把根目录零散的 `.md / .xlsx / .py / settings.xml` 逐步归档到对应目录
- 修复根目录当前异常的 `.git` 目录后，再把这里作为正式 git 仓库使用
